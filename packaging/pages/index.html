Kantele

A UPnP/DLNA music server for amplifiers and streamers. One static binary on one port, with no runtime to install and no request to the internet.

Synology

In Package Center, open Settings, then Package Sources, then Add, and give it this address:

https://gaelsimon.github.io/kantele/index.json

Kantele then appears in Package Center, and every later version arrives there as an update. One package runs on every model. Nothing is signed, so the trust level has to allow any publisher.

macOS and Linux

Take the archive for your machine from the latest release and run the installer inside it. On macOS it installs a launch agent, on Linux a systemd service.

Then

Open http://localhost:8200/config, choose a music folder, and the amplifier finds the server on its own. What the first run looks like says what to expect while the library is read.

What it does not do

It does not transcode, play video, or reach a streaming service. There is no password on it, so it belongs on a home network and not on the open internet. It asks nothing of the internet either: no account, and no request of its own to anywhere.
